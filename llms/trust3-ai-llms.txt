# Trust3 AI

> Trust3 AI is the agent-first trust layer for the enterprise: it discovers every AI agent running across platforms like Databricks and Microsoft Copilot Studio, scores each one with a 1.0-10.0 Trust Score, evaluates agents against policy packs (NERC CIP, EU AI Act, FERC, internal AI governance), and gates new agents through approval workflows. Founded by the creators of Apache Ranger and Apache Atlas (the team behind Privacera), backed by Insight Partners, Sapphire Ventures, Battery Ventures, Accel, Cervin Ventures, and Point72 Ventures.

Programmatic access is through scoped API keys: AI Assets Collectors authenticate to the Trust3 API server (the public AI Governance API edge) with a Trust3 API key, and external AI clients connect over the Model Context Protocol using an MCP (read) scoped key with the x-trust3ai-key header.
